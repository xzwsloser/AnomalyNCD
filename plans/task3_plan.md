# 任务3：下载服务器日志与 CSV 输出

## 目标

从训练服务器 `~/anomaly_ncd/AnomalyNCD/outputs` 目录下载日志文件和 CSV 文件到本地仓库的 `outputs/` 目录；不下载 `.zip` 压缩包、checkpoint 和其他模型权重文件。

## 背景

用户最初要求下载两个 `.zip` 输出压缩包，随后明确取消大文件下载，只取回实验日志与 CSV 结果。服务器连接方式保存在本仓库被忽略的本地私有文件 `server_private.private.md` 中；不得把 IP、用户名、私钥路径等敏感信息写入任何会被 git 跟踪的文件。

## 改动方案

### 涉及文件

- `outputs/`：本地接收服务器输出的目标目录，若不存在则创建。
- `sessions/task3_session.md`：计划执行完成后记录实际下载文件、大小、耗时、验证结果与问题。
- `plans/index.md`：登记任务3计划状态。
- `sessions/index.md`：执行完成后登记任务3记录状态。

### 具体修改与执行步骤

1. 读取本地私有文件 `server_private.private.md`，获取 SSH 连接命令；该内容仅用于本次执行，不写入计划、session 或 git 跟踪文件。
2. 通过 SSH 查询服务器 `~/anomaly_ncd/AnomalyNCD/outputs` 目录，列出 `*.log`、`*.txt` 日志文件与 `*.csv` 文件的相对路径、大小和修改时间；同步确认不包含 checkpoint 或权重文件。
3. 创建本地 `outputs/` 目录，并检查本地剩余磁盘空间是否充足。
4. 使用 `scp` 通过 SSH 下载匹配的日志与 CSV 文件；`scp` 自带文件传输进度显示。
5. 下载完成后对比服务器端与本地文件大小，并计算/对比本地 SHA-256；如需比对服务器端校验值则一并确认。
6. 在 `sessions/task3_session.md` 与对应 `index.md` 中填写执行结果。

## 验证方式

- `scp` 输出必须包含可视化进度信息，传输完成后不报错。
- 本地 `outputs/` 目录中应包含服务器端筛选出的日志与 CSV 文件；不得下载 `.zip`、checkpoint 或权重文件。
- 对比服务器与本地文件字节数；如服务器端可计算校验值，则同时对比校验值。
- 检查 `git status`，确认没有误将敏感信息或大文件加入 git 跟踪范围。

## 风险与依赖

### 依赖

- 本地能够读取 `server_private.private.md`。
- 本地可用 `rsync` 与 SSH。
- 服务器允许当前 SSH 账号访问目标目录并建立数据传输连接。

### 风险

- 服务器或网络不可用会导致下载中断；必要时根据 `rsync` 支持情况重试断点续传。
- 日志/CSV 文件通常体积较小，但仍会占用本地磁盘空间；开始前检查本地剩余空间。
- 使用通配符下载时需先列出匹配清单，避免误下载 `.zip`、checkpoint 或权重文件。
- 下载命令的 SSH 参数属于本地敏感配置，不会被记录到 git 跟踪文档。
